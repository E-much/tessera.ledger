# Motion reference — John C. Odunayo

Standing creative reference for motion design on any project in this repo.

- X: https://x.com/johncodunayo
- Portfolio: https://johnodunayo.my.canva.site (headline: "The God of Motion Design!")
- Studied: Nov 2026 — 55 portfolio video files (~14 distinct pieces), sampled as 16-frame sheets
  in [`frames/`](frames/) and measured for cut rate.

> How to use this: when a new project comes in, read this file, skim the frame sheets, then
> answer **"which of his modes fits, and what would the piece look like?"** using the playbook
> at the bottom. Borrow techniques and pacing, not his clients' assets or footage.

---

## 1. His signature, in one paragraph

Dark, glowing, premium-tech look. Near-black canvases lit by a single soft gradient bloom
(mint-green, electric blue, or violet), clean geometric sans type that **types on, blurs in or
kinetic-slams** onto the beat, and real product UI (dashboards, phones, laptops, code editors)
floated in 3D space with a slow camera drift. Story is always **problem → tension → product
reveal → tagline + CTA end card**. He mixes in pop-culture/meme reaction clips (black-and-white,
grainy) for comic beats, and leans hard on cursor-driven "someone is using the product"
storytelling. Primary tool: After Effects with 3D layers/cameras (his breakdowns show AE
gizmos and camera rigs), plus AI-generated stills/stock for footage-heavy work.

## 3. Recurring techniques (the toolbox)

**Composition & light**
- Near-black base + one off-axis gradient bloom (mint `#3CF2B0`-ish, cyan `#29B6FF`-ish, violet `#7B4DFF`-ish). Never flat colour fields.
- Glow on the hero word/button only; everything else muted grey.
- Product UI shown on real device mockups, tilted in 3D, with slow push-in/parallax.
- Depth via blur: background elements defocused, hero sharp; logos often **blur-to-focus** on reveal.

**Type**
- Clean geometric sans (Inter/Manrope/Satoshi feel) for product work; heavy condensed caps (Bebas/Anton feel) for YouTube/hype.
- Typewriter with blinking caret; word-by-word pop on VO; **mixed weight and baseline in one line** for emphasis.
- One highlighted keyword per line (colour or glow), not whole sentences.

**Motion**
- Cursors as characters: named multiplayer cursors, pixel arrows, glowing hand pointer — they *click* things to trigger the next beat.
- Hard ease-out snaps for UI elements; whip-pan / radial-blur transitions between scenes.
- Numbers always animate (counters, +$ values, percentage chips).
- Error/problem states in red (toasts, circle-slash) → resolved by the product in brand colour.
- Glitch / scanline / chromatic split on text as accent, not throughout.

**Story & pacing**
- Hook in the first 2s (a question, a bold claim, or a cursor clicking).
- Problem told with relatable footage or meme clips (desaturated) → product scenes in full colour.
- Pacing by format: product explainers 2–12s shots (continuous camera); hype/teasers ~1s; vertical talking-head ~0.6s.
- End card: logo + one-line tagline + CTA pill (Join the waitlist / Book / QR code), held 2–3s.

## 4. Playbook — matching a project to a mode

| Project is… | Start from | Why |
|---|---|---|
| Developer tool, SDK, API, no-code builder, SaaS | **A** (cursor explainer) | Shows real workflow; cursors make it human. |
| Exchange, wallet, DeFi, trading, payments, fintech | **B**, with **D** for the teaser cut | Mint/black reads "money + trust"; meme cut for X virality. |
| DAO, protocol, governance, infra, AI-agent network | **C** (HUD) | Abstract systems need diagrams: orbits, nodes, chips. |
| Waitlist / launch announcement for X | **D** (≤35s, ~1s cuts) | Built for timeline attention + meme literacy. |
| Local business, consumer brand, OOH/QR campaign | **E** or the salon-style vertical | Short, loopable, clear CTA. |
| Founder/creator content, course, personal brand | **F** | Caption-driven retention editing. |
| Long-form YouTube, story, case study | **G** or **H** | Stock/AI visuals carry runtime cheaply. |

**When suggesting for a project, always deliver:**
1. Chosen mode(s) + one-line reason.
2. Format, length, aspect ratio(s).
3. Palette (bloom colour from the project's brand) and type pairing.
4. Beat sheet: hook → problem → product → proof → tagline/CTA, with rough timings.
5. 3–5 signature moments borrowed from the toolbox (e.g. "named cursor drags the trade ticket", "blur-to-focus logo").
6. Assets needed from the project (UI screens, logo SVG, VO script, footage).
7. Build notes: After Effects (3D camera, glow, motion blur) for the hero piece; Rive/Lottie or CSS/Framer Motion if it must run in-product or on the site.
